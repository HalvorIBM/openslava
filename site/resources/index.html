    🔁 FDE Engagement Motions¶

    Motion Duration Stage Description
    Motion 1 — Win the Developers 2–4 weeks Pre-sales Prove Bob on real client code; build developer conviction; enable the license decision. The Bobathon is the primary delivery mechanism.
    Motion 2 — Embedded Activation 1–2 months Post-sales Drive seat activation and durable consumption in accounts that have purchased but aren't using Bob. Bobathons used to address skills gaps.
    Motion 3 — Scaled Pilot Up to 60 days Design → Deploy Take one use case to user acceptance — not a throwaway PoC. A 2–3 week pilot is the entry point.
    Deployment Arc & Gates Up to 12 months Embed → Build → Transfer Lifecycle framework governing longer FDE engagements.
