# Beginner Track — Lab B1 Code

Lab B1 ("Explore Modes & Build the OpenSlava 2026 Welcome App") has **no pre-existing starter code** — that's intentional.

Attendees scaffold the entire React + Vite app live during the lab using IBM Bob. Bob runs `npm create vite`, creates all components, and writes the confetti helper — the blank folder is the starting point.

**Follow the lab guide:** [docs/labs/openslava-beginner.md](../../docs/labs/openslava-beginner.md)

Labs B2 and B3 use the shared `galaxium-travels/` folder at the repo root.
